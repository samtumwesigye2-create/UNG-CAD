# UNG-CAD

Source-controlled home for UNG CAD and additive-manufacturing projects.

## Manufacturing projects

- `projects/draco-mini/` — DRACO-Mini Gen-1 compact printable enclosure project.

## DRACO-Mini baseline

- Overall target envelope: approximately 110 x 110 x 135 mm
- Windowless recessed camera aperture
- Screwless/interlocking external enclosure
- Removable electronics cartridge
- Pi Zero 2 W compartment
- Raspberry Pi Camera Module 3 NoIR pocket
- Dual MG90S-class servo bays
- Separate power/wiring compartment
- Nominal mating clearance: 0.35 mm (validate with fit coupon before full print)

The first manufacturing milestone is the dimensional/fit validation package before production STL/STEP export.
